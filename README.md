# Holberton School Interview Preparation

This repository contains solutions to various coding interview problems and challenges from Holberton School. Each directory represents a different problem or algorithm implementation.

## Projects

### Algorithms & Data Structures

- **[Advanced Binary Search](advanced_binary_search/)** - Advanced binary search implementation
- **[AVL Trees](avl_trees/)** - AVL tree validation and operations
- **[Heap Extract](heap_extract/)** - Heap extraction algorithm
- **[Heap Insert](heap_insert/)** - Heap insertion operations
- **[Heap Sort](heap_sort/)** - Heap sort algorithm implementation
- **[Linear Skip](linear_skip/)** - Skip list search algorithm
- **[Merge Sort](merge_sort/)** - Merge sort algorithm
- **[Radix Sort](radix_sort/)** - Radix sort implementation
- **[Sorted Array to AVL](sorted_array_to_avl/)** - Convert sorted array to AVL tree

### Linked Lists

- **[Double Circular Linked List](double_circular_linked_list/)** - Implementation of doubly circular linked list
- **[Find the Loop](find_the_loop/)** - Detect loop in linked list

- **[Linked List Cycle](linked_list_cycle/)** - Detect cycle in linked list
- **[Linked List Palindrome](linked_list_palindrome/)** - Check if linked list is palindrome
